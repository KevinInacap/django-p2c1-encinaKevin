## 🎯 Descripción y Objetivo

Este repositorio contiene la arquitectura **Back End** para el proyecto **Proyecto Integrado / EcoEnergy**, desarrollada con **Python** y el framework web **Django**.

Su objetivo principal es servir como base estructurada para la lógica de negocio, procesamiento de datos y servicios del servidor de la plataforma EcoEnergy.

---

## 🛠️ Requisitos Previos

Asegúrate de contar con los siguientes componentes instalados en tu sistema local:

| Herramienta | Versión Requerida | Detalle |
| :--- | :--- | :--- |
| **Python** | `3.12.3` | Lenguaje y entorno de ejecución base |
| **Django** | `6.1` | Framework Web Back End |
| **Git Bash** | Última versión | Terminal de comandos recomendada |
